execution context ni tushuntiring?
Execution Context 2 bosqichda ishlaydi:
Creation Phase — JavaScript kodni birinchi o'qib chiqadi, o'zgaruvchilar va funksiyalar uchun xotiradan joy ajratadi hamda this ni aniqlaydi.
Execution Phase — JavaScript kodni qatorma-qator bajaradi, qiymatlarni o'zlashtiradi va funksiyalarni chaqiradi.


ReferenceError qachon sodir bo'ladi.
ReferenceError JavaScript mavjud bo'lmagan yoki scope doirasidan tashqaridagi o'zgaruvchiga murojaat qilinganda yuz beradi. Shuningdek, let va const o'zgaruvchilariga initialization qilinishidan oldin murojaat qilinganda ham ReferenceError hosil bo'ladi.

TypeError qachon sodir bo'ladi.
TypeError qiymat mavjud bo'lsa ham, unga mos bo'lmagan amal bajarilganda yuz beradi. Masalan, stringni funksiya sifatida chaqirish, null yoki undefined dan property olish, yoki mavjud bo'lmagan metodni ishlatish TypeError keltirib chiqaradi.


Asinxron va Sinxron dasturlashni tushuntirib bering
Sinxron dasturlashda kod qatorma-qator bajariladi va har bir operatsiya tugamaguncha keyingisi boshlanmaydi. Asinxron dasturlashda esa uzoq davom etadigan operatsiyalar (API, fayl o‘qish, timerlar) fon rejimida bajariladi va dastur boshqa kodlarni ishlashda davom etadi. JavaScriptda asinxronlik Callback, Promise va Async/Await yordamida amalga oshiriladi.

Arrayning slice va splice methodlarini asosiy farqi nimada.
slice() arrayning bir qismini olib yangi array qaytaradi va original arrayni o'zgartirmaydi. splice() esa original arrayni o'zgartiradi, elementlarni qo'shish, o'chirish yoki almashtirish uchun ishlatiladi.


Event Looping to’lliq tushuntiring.
JavaScript Single Threaded til bo‘lib, bir vaqtning o‘zida bitta operatsiyani bajaradi. Asinxron operatsiyalar (setTimeout, fetch, DOM eventlar) Web API larda bajariladi. Ular tugagach Callback Queue yoki Microtask Queue ga tushadi. Event Loop Call Stack bo‘shashini kutadi va navbatdagi tasklarni Stack ga yuboradi. Muhim qoida: Microtask Queue (Promise, async/await) har doim Macrotask Queue (setTimeout, setInterval) dan oldin bajariladi.

Mikro va makro tasklarni to’lliq tushuntiring
JavaScriptda asinxron vazifalar ikki navbatga bo'linadi: Microtask Queue va Macrotask Queue. Promise.then, catch, finally, queueMicrotask va await dan keyingi kodlar Microtask Queue ga tushadi. setTimeout, setInterval va DOM eventlari esa Macrotask Queue ga tushadi. Event Loop Call Stack bo'shagandan keyin avval barcha Microtask larni bajaradi, so'ng Macrotask larni bajaradi. Shu sababli Promise callbacklari odatda setTimeout(..., 0) dan oldin ishlaydi.

Undefined va null ni farqi
undefined — o'zgaruvchiga qiymat berilmaganda JavaScript tomonidan avtomatik beriladigan qiymat. null esa dasturchi tomonidan ataylab "bo'sh qiymat" sifatida beriladi. undefined ning turi undefined, null esa tarixiy sababga ko'ra object turiga ega. undefined == null true, lekin undefined === null false bo'ladi.


?? operator ini ishlashini tushuntirib bering
?? (Nullish Coalescing Operator) chap tomondagi qiymat null yoki undefined bo'lsa, o'ng tomondagi qiymatni qaytaradi. || operatoridan farqli ravishda 0, false va "" kabi qiymatlarni noto'g'ri ravishda almashtirmaydi. Shu sababli default qiymat berishda ko'pincha ?? ishlatish tavsiya etiladi.
